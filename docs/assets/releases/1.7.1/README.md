# macOS 1.7.1 assets

`notification-reset-ko.png` is the original user-provided Notification Center
screenshot, published at the user's explicit request. It shows a real Codex
weekly-reset notification received with 1.7.0, before the icon update. The
old orange icon is intentionally retained as evidence of the actual capture;
this is not a mockup of the new icon.

The screenshot contains no account identifier, conversation, or credential.
No crop, retouch, or icon replacement was applied.

The new app icon comes from @jwoo5377's PR #4. Its light/dark README previews
are in `docs/screenshots/`, and the macOS app bundles the dark `.icns` variant.
This is not automatic macOS appearance switching. Windows assets are unchanged.
