# macOS 1.6.2 screenshots

These PNGs were rendered from the app's SwiftUI views by
`ReleaseScreenshotTests.testRenderPublicReleaseScreenshotsWithDemoData`.

All account and usage values are synthetic. No live account fetch, credentials,
conversation content, or project names are included. Dates and reset countdowns
reflect the rendering time. The screenshots demonstrate the pending daily-token
state intentionally; they are not a claim about a real account's usage.

The test renders the three themes in Korean and English. Selected outputs from
`/private/tmp/ClaudeUsage-release-previews` are published here for the website,
READMEs, and release notes. Existing screenshots of unchanged settings, history,
and the companion lineup remain in their original asset directories.
