# ClaudeUsage 1.7.1 for macOS

**새 앱 아이콘과 실제 알림 수신 사례**를 반영한 패치 릴리즈입니다. macOS 13 이상, Intel + Apple Silicon Universal, **빌드 23**입니다. 기존 사용량 조회·테마·위젯·알림 로직은 1.7.0과 같습니다.

## 새 아이콘

- [@jwoo5377](https://github.com/jwoo5377)의 [PR #4](https://github.com/jaewoo4200/ClaudeUsage/pull/4)를 원저자 커밋을 보존해 통합했습니다. 1.7.0 헤일로 바 테마에서 가져온 세 줄 게이지 디자인입니다.
- macOS 앱 아이콘, 홈페이지, favicon과 아이콘 원본·미리보기를 갱신했습니다.
- 앱은 다크 아이콘을 사용합니다. 한국어·영어 README는 화면 모드에 따라 라이트·다크 미리보기를 선택합니다. macOS 앱 아이콘의 자동 모드 전환 기능은 아닙니다.
- Windows `App.ico`와 Windows 배포물은 변경하지 않았습니다.

## 실제 알림 화면

사용자가 공개를 요청한 원본 화면을 README와 홈페이지에 추가했습니다. Codex의 **7일 사용량 초기화** 알림이 macOS 알림 센터에 표시된 사례입니다.

![실제 Codex 주간 초기화 알림](https://raw.githubusercontent.com/jaewoo4200/ClaudeUsage/v1.7.1/docs/assets/releases/1.7.1/notification-reset-ko.png)

이 캡처는 **1.7.0에서 수신한 알림**이므로 이전 주황 아이콘이 보입니다. 새 아이콘을 합성하거나 수신 내용을 바꾸지 않았습니다. 1.7.1의 실제 알림 수신을 새로 촬영한 이미지는 아닙니다.

설정에서 사용량 70%·90% 경고, 서버 조회로 확인한 초기화, 로그인·연속 조회 오류 알림을 각각 켤 수 있습니다. **알림 권한 요청 → 테스트 알림**으로 확인하세요. 집중 모드와 macOS 배너 설정에 따라 표시 방식이 달라질 수 있습니다.

## 설치와 검증

- `ClaudeUsage-1.7.1.dmg`: **4,439,303 bytes**, 버전 **1.7.1 / 빌드 23**.
- 기존 앱을 종료하고 Applications의 앱을 교체한 뒤 실행하세요. 기존 테마·위젯 위치·알림 설정·사용 기록은 유지됩니다.
- **115개 테스트 통과, 실패 0개**, 선택형 실계정/Codex 펫 테스트 2개 제외.
- DMG 무결성, Universal 아키텍처, 앱 번들 서명, 새 아이콘의 16~1024px 리소스와 패키지 내 원본 일치를 확인했습니다.
- ad-hoc 서명이며 **Apple Developer ID 서명·공증은 없습니다**. 공식 배포 출처와 아래 SHA-256을 확인하세요. 설치 앱의 Finder·알림 센터 아이콘 캐시 갱신 여부는 자동 테스트 대상이 아닙니다.
- 이번 릴리즈에는 Windows 바이너리가 없습니다.

## English Summary

Version **1.7.1 (23)** ships @jwoo5377's three-row Halo gauge app icon from PR #4, preserving the original contribution. The app uses the dark icon; README previews support both light and dark appearance. Existing application behavior is unchanged.

The README and website now include a user-supplied, unedited screenshot of a real Codex weekly-reset notification received on **1.7.0**, so the screenshot intentionally retains the old icon. The Universal DMG passed integrity/signature/resource checks and 115 tests, with two opt-in live checks skipped. It is ad-hoc signed, not Developer ID signed or notarized. Windows remains separate.
