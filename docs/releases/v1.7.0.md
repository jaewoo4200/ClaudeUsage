# ClaudeUsage 1.7.0 for macOS

새 게이지 디자인 세 가지와, Claude나 Codex 중 하나만 표시하는 옵션을 추가했습니다. 이 릴리스는 macOS용이며, 저장소의 Windows 개발자 알파는 별도 배포입니다.

## 새 디자인

- **세 가지 테마:** 도넛, 헤일로 바, 오라 중에서 고를 수 있습니다. 드롭다운과 위젯은 항목마다 남은 시간과 사용률을 큰 숫자로 보여 주는 줄로 구성됩니다.
- **도넛:** 사용률이 오를수록 고리가 파랑에서 주황, 빨강으로 이어집니다. 90~95% 구간에서는 고리 전체가 빨강으로 물들어 위험 단계가 바로 보입니다. % 숫자는 여유, 경고, 위험 세 가지 색만 씁니다.
- **헤일로 바:** 그라데이션 막대 둘레로 빛이 번집니다. 남은 시간과 %를 막대 높이에 꼭 맞게 크게 표시하고, 채워진 부분 위의 글자는 바탕색으로 빠집니다.
- **오라:** 막대 테두리 없이 사용률만큼 빛이 퍼지고, 그 위에 남은 시간과 %를 표시합니다. 빛 위에서도 글자가 읽히도록 글자 둘레에 바탕색 그림자를 둡니다.
- **같은 크기:** 세 테마의 드롭다운과 위젯 높이가 같아서 테마를 바꿔도 창 크기가 그대로입니다.
- **색:** 주황과 빨강은 경고와 위험에만 씁니다. 선택 표시, 버튼, 토글 같은 강조색은 각 테마의 여유 단계 색(도넛·헤일로 바는 파랑, 오라는 하늘색)을 씁니다. 다크 모드는 라이트 모드보다 조금 어두운 색을 따로 쓰고, 작은 글자와 연결 표시 점의 명암 대비를 높였습니다.
- **머리 영역:** 드롭다운과 위젯 모두 서비스 아이콘, 이름(Claude는 주황, Codex는 남보라), 이름 오른쪽 위의 연결 점, 요금제를 한 줄로 보여 줍니다. 연결 상태 문구는 이름에 마우스를 올리면 보입니다.
- **설정:** 테마 목록에서 각 테마의 게이지를 크게 미리 볼 수 있습니다. 설정 창 위쪽 로고도 테마마다 바뀝니다. 도넛은 색 띠 고리, 헤일로 바는 반쯤 찬 막대, 오라는 빛 위의 C입니다.

## 남은 시간 표기

- 0이 된 앞 단위는 뺍니다. 7일 창은 하루 이상 남으면 `3d 11h`(헤일로 바·오라) 또는 `3d 11h 19m`(도넛), 하루 미만이면 `11h 19m`, 1시간 미만이면 `0:45:12`로 표시합니다.
- 5시간 창은 항상 시:분:초(`2:29:59`)로 표시합니다. 초기화 시각이 지나면 다음 새로고침까지 `0:00:00`으로 표시합니다.
- 남은 시간 숫자는 앱에 포함한 Barlow Condensed 서체(SIL Open Font License 1.1)로 표시합니다.

## 새 기능과 수정

- **표시할 서비스:** 설정 > 표시할 서비스에서 Claude나 Codex를 끌 수 있습니다. 끈 서비스는 메뉴 막대, 드롭다운, 위젯에서 빠지고 사용량도 조회하지 않습니다. 오늘 토큰 합계, Mimo 기분, 사용 기록도 켠 서비스만 기준으로 계산합니다. 하나만 켜면 위젯은 배치와 상관없이 한 장으로 표시합니다. 둘 다 끌 수는 없습니다.
- **주간 사용 구성:** 7일 줄의 "구성" 버튼으로 펼치고 접습니다. 드롭다운에서는 7일 줄에 마우스를 올려도 펼쳐집니다. 펼치면 7일 게이지가 Code, 채팅, Cowork, 기타 색으로 나뉘고, 아래에 각 비율이 표시됩니다.
- **위젯 이동:** 위젯을 끌어도 움직이지 않던 문제를 고쳤습니다. 옮긴 위치는 다음 실행에도 유지됩니다.

사용량을 가져오는 방식은 1.6.3과 같습니다. 설정에서 끈 서비스는 조회하지 않습니다.

## 설치 및 검증

- macOS 13 이상, Intel 및 Apple Silicon을 지원하는 Universal DMG입니다.
- 파일: `ClaudeUsage-1.7.0.dmg` (〔빌드 후 기입〕 bytes), 버전 1.7.0, 빌드 19.
- Apple Developer ID 서명 및 공증은 적용되지 않았습니다. macOS 보안 경고가 나타날 수 있으므로 [README의 설치 안내](https://github.com/jaewoo4200/ClaudeUsage#-처음-실행할-때-읽어주세요)를 먼저 확인하세요.
- 기존 ClaudeUsage를 종료하고 새 앱으로 교체한 뒤 실행하세요. 고른 테마, 위젯 위치, 사용 기록 등 기존 설정은 그대로 유지됩니다.
- macOS 자동 테스트 **〔N〕개 통과**, DMG 무결성 검사 통과. Windows 빌드는 이번 검증에 포함하지 않았습니다.
- 함께 첨부한 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.

```text
〔빌드 후 기입〕  ClaudeUsage-1.7.0.dmg
```
