# ClaudeUsage 1.7.0 for macOS

기존 테마를 유지하면서 새 게이지 디자인, 알림, 위젯 주간 구성 고정, 로컬 Codex 펫 연동을 추가했습니다. **macOS 13 이상 / Intel + Apple Silicon Universal / 빌드 22** 릴리즈입니다. Windows 알파는 별도이며 이번 배포에는 Windows 바이너리가 없습니다.

## Contributors

새 디자인과 홈페이지 개선에 기여한 **[@jwoo5377](https://github.com/jwoo5377)** 님께 감사합니다. [PR #2](https://github.com/jaewoo4200/ClaudeUsage/pull/2)의 도넛·헤일로 바·오라, 표시할 서비스 설정, 홈페이지·스크린샷, DMG 파일명 개선을 원저자의 세 커밋을 보존해 통합했습니다. 프로젝트 개발·통합·유지보수: [@jaewoo4200](https://github.com/jaewoo4200).

## 주요 변경

- **6가지 테마:** 기존 당근·토스·하이브리드와 저장된 선택값을 유지하고 도넛·헤일로 바·오라를 별도 선택지로 추가했습니다. 새 게이지 3종은 같은 행 높이를 사용합니다.
- **서비스 선택:** Claude 또는 Codex를 끄면 해당 서비스의 조회·로컬 토큰 스캔을 멈추고 화면·합계·펫 추이에서 제외합니다. 기존 기록을 삭제하지 않습니다.
- **위젯 주간 구성:** 모든 테마에서 Claude 7일 줄을 가리키면 펼쳐집니다. 가로 배치는 Codex 아래, 세로·전환·Claude 단독 배치는 Claude 아래에 표시합니다. 핀 버튼으로 고정하며 선택은 재실행 후에도 유지됩니다. 테마 전환 후 첫 마우스 오버가 막히던 문제도 수정했습니다.
- **알림:** 선택형 70%·90% 경고, 서버 조회로 확인한 초기화, 로그인 만료·연속 조회 실패 안내를 추가했습니다. 별도 권한 요청·테스트 버튼과 오류 코드 표시를 제공하며 중복 요청을 막습니다. 사용자가 실제 Mac에서 테스트 알림 수신을 확인했습니다.
- **업데이트 안내:** 수동 또는 선택형 하루 1회 GitHub Releases 확인을 지원합니다. 푸시 서버·자동 다운로드·자동 설치는 없습니다.
- **Google 계정 고급 연결:** 기본 브라우저에서 로그인한 뒤 본인의 Claude `sessionKey`를 직접 입력하고 검증해 Keychain에 저장할 수 있습니다. 자동 OAuth 연결이나 브라우저 쿠키 가져오기가 아니며 이메일 로그인도 유지합니다.
- **Codex Pet:** 이 Mac의 Codex에서 선택한 로컬 펫과 v1/v2 이미지 시트를 지원합니다. 클라우드로 이전된 선택도 로컬 원본이 남아 있을 때 연결합니다. 클라우드 전용 펫은 지원하지 않으며 개인 펫·Codex 내장 이미지는 배포 파일에 포함하지 않습니다.
- **조회 정확성:** Codex의 이름별 한도를 우선 처리하고 누락된 한도를 정상값으로 오인하지 않습니다. Claude의 활성 조직 선택과 스트리밍 메시지별 토큰 중복 합산도 보완했습니다.
- **앱 번들 서명:** 앱 ID, Info.plist, 리소스를 포함한 ad-hoc 서명을 패키징 단계에서 검증합니다. Apple Developer ID 서명이나 공증은 아닙니다.

## 설치 및 검증

- 파일: `ClaudeUsage-1.7.0.dmg`, **5,201,835 bytes**, 버전 **1.7.0 / 빌드 22**.
- 기존 앱을 종료하고 Applications의 앱을 교체한 뒤 실행하세요. 테마·위젯 위치·사용 기록 등 기존 설정은 유지됩니다.
- **115개 자동 테스트 통과, 실패 0개**. 별도 실행이 필요한 실계정/Codex 펫 검사 2개는 이번 회귀 테스트에서 제외했습니다. 6개 테마·위젯 배치·한국어/영어 렌더링, 알림 상태와 요청 오류·재시도, 호버 전환을 검사했습니다.
- Universal 아키텍처, DMG 무결성, 앱 번들 서명을 검증했습니다. 서명·테스트 통과가 모든 계정의 로그인 성공이나 보안을 보증하는 것은 아닙니다. Google 고급 연결의 실계정 전체 흐름과 Windows 실기 검증은 별도입니다.
- Developer ID 서명·공증은 없습니다. [처음 실행 안내](https://github.com/jaewoo4200/ClaudeUsage#-처음-실행할-때-읽어주세요)를 확인하세요.
- Codex GUI를 계속 켜 둘 필요는 없지만, 호환되는 Codex 실행 파일과 로그인 세션이 필요합니다. Claude 한도는 공식 문서화되지 않은 endpoint에 의존하므로 제공자 변경에 영향을 받을 수 있습니다.
- 첨부한 `ClaudeUsage-1.7.0.dmg.sha256`과 비교해 다운로드 무결성을 확인할 수 있습니다.

## English Summary

Version 1.7.0 (build 22) preserves Daangn, Toss, and Hybrid while adding Donut, Halo Bar, and Aura from **@jwoo5377's PR #2**, with the original authored commits preserved. It adds persistent widget breakdown pins, fixes hover after theme changes, introduces opt-in notifications and release checks, and supports advanced manual browser-session connection and locally available Codex pets.

The macOS Universal DMG passed integrity/signature validation and 115 automated tests; two opt-in live checks were skipped. The user confirmed actual notification delivery. The app is ad-hoc signed, **not Developer ID signed or notarized**. Google connection is manual, cloud-only pets are unsupported, and Windows remains a separate alpha.
