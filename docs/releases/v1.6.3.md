# ClaudeUsage 1.6.3 for macOS

ChatGPT/Codex 앱 업데이트 후 메뉴바와 위젯에서 Codex 사용량을 조회하지 못하는 문제를 수정했습니다.

## 수정 사항

- 최신 앱에 포함된 `Contents/Resources/codex-cli/CodexCLI.app/Contents/MacOS/codex` 실행 파일을 찾습니다. 기존 `Contents/Resources/codex`도 계속 지원합니다.
- `/Applications`와 `~/Applications`의 ChatGPT/Codex 앱을 확인하고, 기존 `.local/bin`, Homebrew 및 `/usr/local/bin` CLI 경로를 유지합니다. 조회할 때마다 경로를 다시 확인하므로 실행 중 앱이 업데이트되어도 새 위치를 찾습니다.
- 초기화권 개수만 제공되고 상세 목록이 `null`이거나 생략된 경우에도 Codex 한도 조회가 실패하지 않습니다. 제공되지 않은 만료일을 만들어 표시하지 않습니다.
- 계정, 인증정보, 사용 기록 또는 위젯 설정을 초기화하지 않습니다. 사용률을 고정하거나 별도 값으로 대체하지 않습니다.

## 검증 및 설치

- macOS 자동 테스트 64개 통과. 새 위치의 설치된 Codex 실행 파일을 통한 실계정 읽기 전용 조회를 포함합니다.
- macOS 13 이상, Intel 및 Apple Silicon용 Universal DMG. 버전 1.6.3, 빌드 18.
- Apple Developer ID 서명과 공증은 적용되지 않았습니다.
- 기존 ClaudeUsage를 종료하고 새 앱으로 교체한 뒤 실행하세요. Codex 로그인 세션이 유효하면 GUI 앱 창을 계속 열어 둘 필요는 없습니다.
- Windows 알파는 이번 macOS 패치 범위에 포함하지 않았습니다.

설치 파일은 `ClaudeUsage-1.6.3.dmg` (4,138,180 bytes)이며, DMG 무결성 검사를 통과했습니다. 첨부된 `.sha256` 파일로 다운로드를 검증할 수 있습니다.

```text
6cdf721c4e3a9bc77c3ef55cd4d5a6c6c46b7ce6834d57fcd52fcb8da3890abc  ClaudeUsage-1.6.3.dmg
```

개인 계정의 응답, 토큰, 인증정보 및 진단 로그는 배포 파일에 포함하지 않았습니다. 실행 파일 탐색과 응답 호환성만 변경되어 기존 1.6.2 스크린샷을 그대로 사용합니다.
