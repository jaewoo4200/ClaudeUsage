# ClaudeUsage 1.6.2 for macOS

Claude 주간 사용 내역과 서비스별 오늘 토큰 상세를 추가했습니다. 이 릴리스는 macOS용이며, 저장소의 Windows 개발자 알파는 별도 배포입니다.

## 주요 변경

- **Claude 주간 사용 내역:** Code, 채팅, Cowork 등 이미 사용한 주간량의 서비스별 비율을 표시합니다. `Breakdown`이 별도 0% 한도로 나타나던 문제를 수정했습니다. 이 비율은 한도나 Mimo 최고 사용률에 포함하지 않습니다.
- **위젯별 배치:** 가로 위젯의 위쪽에는 한도와 주간 내역, 아래쪽에는 펫과 요약 정보를 나란히 표시합니다. 세로, 전환, 분리 위젯에서도 Claude 내역을 확인할 수 있습니다.
- **오늘 토큰 상세:** 가로 위젯의 오늘 토큰 행 또는 메뉴바 드롭다운의 토큰 버튼에서 서비스별 정확한 수치와 Codex 최근 서버 집계 날짜를 확인합니다. `M`은 백만 토큰입니다.
- **미집계와 0 구분:** 오늘 값이 아직 없으면 집계 대기, 한쪽만 확인되면 일부 집계로 표시합니다. 전날 값을 오늘 합계로 대체하지 않습니다.
- **추이 정확도:** 자정 이후 Claude 캐시와 뒤늦게 도착한 일별 누적값이 최근 증가량에 섞이는 문제를 수정했습니다.
- 한국어와 영어 README 및 홈페이지를 새 스크린샷으로 갱신했습니다.

## 데이터 출처

Claude 한도와 주간 구성은 Claude 계정 응답을 사용합니다. Claude 오늘 토큰은 이 Mac의 Claude Code 로컬 기록, Codex 오늘 토큰은 계정의 서버 일별 집계를 사용하므로 두 값의 범위와 반영 시점이 다릅니다. Codex는 현재 연동 응답에 서비스별 구성 비율을 제공하지 않습니다.

로그인된 호환 Codex 실행 파일이 설치되어 있으면 ClaudeUsage가 로컬 `codex app-server`를 직접 실행하므로 Codex 앱 창을 계속 열어 둘 필요는 없습니다.

## 설치 및 검증

- macOS 13 이상, Intel 및 Apple Silicon을 지원하는 Universal DMG입니다.
- 파일: `ClaudeUsage-1.6.2.dmg` (4,132,362 bytes), 버전 1.6.2, 빌드 17.
- Apple Developer ID 서명 및 공증은 적용되지 않았습니다. macOS 보안 경고가 나타날 수 있으므로 [README의 설치 안내](https://github.com/jaewoo4200/ClaudeUsage#-처음-실행할-때-읽어주세요)를 먼저 확인하세요.
- macOS 자동 테스트 **57개 통과**, DMG 무결성 검사 통과. Windows 빌드는 이번 검증에 포함하지 않았습니다.
- 함께 첨부한 `.sha256` 파일로 다운로드 무결성을 확인할 수 있습니다.

```text
57f8c9346410f7eae50383086ba54b85d2a01f3177bfc95d26c2581a66b7ac90  ClaudeUsage-1.6.2.dmg
```
