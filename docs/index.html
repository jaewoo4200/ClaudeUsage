macOS 1.7.0 · 새 게이지 디자인과 표시할 서비스

세 가지 게이지.
필요한 서비스만.

기존 당근, 토스, 하이브리드 테마와 저장된 선택을 유지합니다. 새로 추가된 도넛, 헤일로 바, 오라까지 총 6가지 중 고르고, Claude와 Codex 중 쓰는 서비스만 켜 둘 수 있습니다. 아래 화면은 새 게이지 디자인의 데모 데이터 예시입니다.

기존 테마는 그대로, 새 디자인은 선택으로. 당근의 주황 링과 토스·하이브리드의 기존 막대 표시를 유지합니다. 새 게이지 3개는 같은 행 높이를 사용하며, 주황과 빨강은 경고와 위험에 사용합니다. 기존 테마로 돌아오면 창 크기도 해당 레이아웃에 맞춰집니다.

위젯을 끌어도 움직이지 않던 문제를 고쳤고, 옮긴 위치는 다음 실행에도 유지됩니다. 고른 테마와 사용 기록 등 기존 설정은 업데이트 후에도 그대로입니다. Codex 한도 선택과 Claude 로컬 토큰 중복 집계도 보완했습니다.

위젯에서도 Claude의 7일 줄이나 주간 구성 제목에 마우스를 올리면 구성이 펼쳐집니다. 가로 배치에서는 Codex 아래, 나머지 Claude 위젯에서는 Claude 사용량 아래에 나타납니다. 핀 버튼으로 펼침을 고정하거나 해제할 수 있고, 선택은 재실행 후에도 유지됩니다. Codex 전용 위젯에는 Claude 구성을 표시하지 않습니다.

macOS 1.7.0: 로그인, 알림, Codex 펫

Google 로그인은 기본 브라우저에서 완료한 뒤 고급 연결에 본인의 Claude sessionKey만 입력합니다. 앱이 세션을 검증해 Keychain에 보관하며 브라우저 쿠키를 자동 수집하지 않습니다. 이메일 로그인도 유지됩니다.

70%·90% 경고, 서버 조회로 확인한 초기화, 연속 조회 실패 알림은 각각 선택해 켭니다. 설정의 알림 권한 요청·테스트 알림 버튼으로 확인하고, 거절한 권한은 macOS 알림 설정에서 변경합니다. 새 버전 안내는 선택형 하루 1회 GitHub Releases 확인이며 푸시 서버나 자동 설치는 없습니다.

Codex Pet은 로컬 선택과 이미지 파일을 읽습니다. 클라우드로 이전된 펫은 로컬 원본이 남아 있을 때만 표시하며 클라우드에서만 존재하는 펫은 지원하지 않습니다. 개인 펫과 Codex 내장 이미지는 배포 파일에 포함하지 않습니다. 기존 9종 펫과 사용자의 선택은 유지합니다.

macOS 1.7.0은 115개 자동 테스트를 통과했고 실제 테스트 알림 수신도 확인했습니다. Google 고급 연결의 실계정 전체 흐름과 Windows 실기 검증은 별도입니다.

배포

self-contained ZIP

.NET 런타임은 포함됩니다. ZIP 전체를 압축 해제해 실행하며, 서명 설치 프로그램/MSIX나 win-arm64 패키지는 아직 없습니다.

각 공급자가 소유

Codex는 설치된 codex app-server를 사용합니다. Claude는 WebView2 Evergreen의 격리 로그인 창을 사용하고 세션 쿠키 헤더를 현재 사용자 DPAPI로 암호화합니다.

켠 경우에만 5분 간격·최대 14일/4,200개 숫자를 저장하고, Claude Code JSONL에서는 오늘의 시각과 숫자형 usage 필드만 합산합니다.

Windows alpha — English summary

This is an unsigned, self-contained developer alpha for Windows 11 x64, separate from the stable macOS download. The .NET runtime is bundled; Claude sign-in requires Microsoft Edge WebView2 Evergreen. There is no signed installer/MSIX or ARM64 package yet.

Codex usage comes from the installed codex app-server without reading %USERPROFILE%\.codex\auth.json. Claude uses an isolated WebView2 sign-in profile and stores its session cookie encrypted for the current Windows user with DPAPI. Local history and scanning numeric usage fields from Claude Code JSONL are off by default.

Claude quotas depend on an undocumented Anthropic endpoint that may change or be restricted without notice. See the Windows guide for installation, SHA-256 verification, build commands, paths, and privacy details.
